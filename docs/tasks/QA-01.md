# QA-01 — 계산 계약·경계값 자동 검증

## 연결 문서
- SRS: `AC-001~006`, `AC-010`, `NFR-001`, `NFR-002`
- Spec: `docs/specs/TEST_SPEC.md`

## 목표
계산 규칙이 코드 변경 뒤에도 같은 경계와 정답을 유지함을 자동으로 증명한다.

## 구현 범위
- [ ] `T-AC001~006`, `T-AC010` Vitest
- [ ] 50,000원·15% 양쪽 경계값
- [ ] 정답셋·배분 합·동률·근거 누락 테스트
- [ ] 금지어·비밀키·개인정보 정적 검사

## 제외 범위
- 사용자 선택률·사용성 조사

## 완료 조건
- [ ] P0 계산 테스트 전부 통과
- [ ] 알려진 실패와 불안정 테스트 0건
