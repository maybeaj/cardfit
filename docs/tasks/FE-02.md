# FE-02 — 미래지출 계획과 변경 조건 입력

## 연결 문서
- SRS: `FR-001`, `FR-006`, `FR-007`, `UI-002`, `UI-003`, `AC-001`, `AC-007`, `AC-010`
- Spec: `docs/specs/TECH_SPEC.md`

## 목표
사용자가 과거 패턴 제안값을 확인·수정하고 별도 조건 화면에서 계산 범위를 정하게 한다.

## 구현 범위
- [ ] 앞으로 12개월 제안값과 출처 표시
- [ ] 자유 카테고리·금액·시점 추가/수정/삭제
- [ ] 모두 삭제/0원 Empty 상태와 다시 채우기
- [ ] 카드 수·신규 허용 조건 화면
- [ ] `이 계획대로 계산하기` 확인 스냅샷

## 제외 범위
- 이벤트 선택 단계, 30% 입력 비율 판정

## 완료 조건
- [ ] 미수정 제안값으로도 명시적 확인 후 진행
- [ ] Empty 상태 결과 요청 0건
