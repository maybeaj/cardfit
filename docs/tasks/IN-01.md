# IN-01 — 프로토타입 실행 기반 구성

## 연결 문서
- SRS: `NFR-002`, `NFR-003`
- Spec: `docs/specs/TECH_SPEC.md`

## 목표
팀원이 한 명령으로 CardFit을 실행하고 같은 검사 명령으로 품질을 확인할 수 있게 한다.

## 구현 범위
- [ ] Next.js App Router, TypeScript, Tailwind CSS 구성
- [ ] Vitest와 Playwright 구성
- [ ] `dev`, `build`, `lint`, `typecheck`, `test`, `test:e2e` 스크립트
- [ ] 환경변수 없이 실행되는 기본 화면

## 제외 범위
- DB, 인증, 실제 API, 배포 계정 설정

## 완료 조건
- [ ] 모든 스크립트가 설치된 의존성 기준으로 실행됨
- [ ] 비밀키·개인정보가 저장소와 번들에 없음
