# FE-03 — 결과·배분·근거·확정 흐름

## 연결 문서
- SRS: `FR-002~005`, `FR-008`, `UI-004~008`, `AC-002~006`, `AC-008`
- Spec: `docs/specs/TECH_SPEC.md`, `docs/specs/CALC_SPEC.md`

## 목표
사용자가 결론만 보는 데서 끝나지 않고 돈을 어디에 결제할지와 계산 근거, 직접 할 다음 행동까지 확인하게 한다.

## 구현 범위
- [ ] 계산 상태와 카드별 신규·유지·정리 조합
- [ ] 변경/유지 결론 배너와 비교 기준선
- [ ] 카드별 결제 배분표
- [ ] 근거 6항목과 미반영 상한
- [ ] 확정 요약·다음 행동·실행 경계 3블록
- [ ] 신규 공식 링크와 세션 상태 복원

## 제외 범위
- 신청·해지 대행, 해지 버튼, 신규 링크 2개 이상

## 완료 조건
- [ ] 단일 조합안 표시
- [ ] 근거 화면 외 확정 진입 0건
- [ ] 유지 결론에서도 배분과 검토 대안 표시
