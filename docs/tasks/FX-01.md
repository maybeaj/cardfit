# FX-01 — Mock Fixture와 계산 정답셋

## 연결 문서
- SRS: `FR-001~006`, `AC-004`, `AC-010`
- Spec: `docs/specs/FIXTURE_SPEC.md`

## 목표
같은 사용자 흐름에서 변경과 유지 결론을 반복 재현할 수 있는 예시 데이터를 제공한다.

## 구현 범위
- [ ] `change_case`, `maintain_case` 데이터
- [ ] 규칙 버전·기준일·제외조건·미반영 상한 출처
- [ ] 단일 조합의 신규·유지·정리 상태와 배분 합 정답
- [ ] 예시 데이터/예시 수치 고지

## 제외 범위
- 페르소나 선택 UI, 실명 사용자 데이터, 실 API 응답

## 완료 조건
- [ ] `186,000원`, `42,000원`, `31,000원` 판정값 재현 가능
- [ ] 출처 없는 미반영 상한 0건
