# FE-01 — 온보딩·예시 연결·현재 진단

## 연결 문서
- SRS: `UI-011`, `UI-012`, `UI-001`, `AC-011`, `AC-012`
- Spec: `docs/specs/TECH_SPEC.md`

## 목표
사용자가 실제 금융 연결로 오해하지 않고 현재 상태를 본 뒤 미래지출 입력으로 진입하게 한다.

## 구현 범위
- [ ] `카드핏.png` 기반 온보딩
- [ ] 예시 데이터 연결 안내와 완료 상태
- [ ] 현재 혜택 요약과 현재 카드 진단
- [ ] `앞으로 쓸 돈 반영하기` CTA

## 제외 범위
- 실제 인증·동의·마이데이터 연결, 페르소나 선택, 최종 조합 판정

## 완료 조건
- [ ] 과거 기준 라벨 2개가 금액과 함께 표시
- [ ] 실제 연결을 뜻하는 문구와 최종 조합 노출 0건
