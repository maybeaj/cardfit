# FE-01 — 랜딩·마이데이터 이용 동의·현재 카드 확인

## 연결 문서
- SRS: `UI-011`, `UI-012`, `UI-001`, `AC-011`, `AC-012`
- Spec: `docs/specs/TECH_SPEC.md`

## 목표
사용자가 실제 금융 연결로 오해하지 않고 현재 상태를 본 뒤 미래지출 입력으로 진입하게 한다.

## 구현 범위
- [ ] 모바일 우선 랜딩/웰컴 화면과 `카드핏.png` 로고
- [ ] `마이데이터 이용 동의하기` 화면과 예시 데이터 안내
- [ ] 예시 데이터 조회 완료 상태
- [ ] 현재 카드와 혜택 확인 화면
- [ ] `앞으로 쓸 돈 반영하기` CTA

## 제외 범위
- 실제 인증·동의 처리·마이데이터 연결, 페르소나 선택, 최종 조합 판정

## 완료 조건
- [ ] 과거 기준 라벨 2개가 금액과 함께 표시
- [ ] 실제 서비스와 같은 동의 흐름을 보여주고, 예시 데이터 이용 사실을 함께 안내
