# DS-01 — 모바일 디자인 시스템과 화면 셸

## 연결 문서
- SRS: `UI-001~008`, `UI-011`, `UI-012`, `NFR-003`
- Spec: `docs/specs/TECH_SPEC.md`, `DESIGN.md`

## 목표
모든 화면이 iPhone 17 기준에서 같은 시각 언어와 이동 규칙을 사용하게 한다.

## 구현 범위
- [ ] 색상·간격·글자·모서리 CSS 토큰
- [ ] AppShell, Header, Card, CTA, Step/Progress, Notice 공통 컴포넌트
- [ ] 402×874와 1440×900 반응형 셸
- [ ] 키보드 포커스와 기본 접근성

## 제외 범위
- 실제 계산과 Fixture 내용

## 완료 조건
- [ ] 가로 스크롤 없이 공통 셸 표시
- [ ] 화면별 계산식·색상 상수 중복 없음
