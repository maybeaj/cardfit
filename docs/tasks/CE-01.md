# CE-01 — 결정론적 계산·게이팅·배분 엔진

## 연결 문서
- SRS: `FR-002~005`, `AC-001~006`, `NFR-001`
- Spec: `docs/specs/CALC_SPEC.md`

## 목표
확정된 12개월 계획을 계산해 카드별 신규·유지·정리 상태와 결제 배분을 반환한다.

## 구현 범위
- [ ] 순수 타입과 입력 스냅샷 검증
- [ ] 확인된 미래 계획의 단일 혜택 계산
- [ ] 최대 2장·신규 최대 1장 후보 생성
- [ ] Net Benefit 이중 임계와 유지 정상 결과
- [ ] 배분·동률·근거 완전성 규칙
- [ ] 경계값 단위 테스트

## 제외 범위
- 화면 렌더링, AI 설명, 외부 API

## 완료 조건
- [ ] 같은 입력 3회 결과 불일치 0건
- [ ] 배분 오차 1원 이하
- [ ] 필수 근거 누락 시 결과 거부
