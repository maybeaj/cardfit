# 05. 용어집

> PRD, SRS, UI와 AI 답변에서 같은 뜻으로 써야 하는 용어만 정의한다.

| 용어 | 정의 | 상태 | 이렇게 쓰지 않는다 | 연결 |
| --- | --- | :---: | --- | --- |
| **Net Benefit** | Gross Benefit에서 연회비와 전환비용을 차감한 연간 순이익 | 🟢 Decision | 단순 “혜택”, “절감액”과 혼용 금지 | FR-003 · D-002 |
| **Gross Benefit** | 연회비와 전환비용 차감 전 12개월 혜택 합계 | 🟢 Decision | Net Benefit과 혼용 금지 | FR-003 |
| **조합안** | 보유 카드의 유지·해지, 신규 추가, 카드별 역할·배분을 함께 담은 실행 단위 | 🟢 Decision | “추천 카드 1장”으로 축약 금지 | FR-003/004/008 |
| **현재 조합 유지** | 변경안이 임계값을 넘지 않을 때 반환하는 정상 결론 | 🟢 Decision | 계산 실패나 빈 결과로 표현 금지 | G3 · AC-004 |
| **전월실적 구간** | 카드 혜택 적용 여부나 한도를 결정하는 직전 기간 이용금액 조건 | 🔵 Fact | 모든 카드에 같은 기준으로 표현 금지 | FR-002/005 |
| **혜택 한도** | 카드 또는 혜택 영역에서 받을 수 있는 최대 할인·적립액 | 🔵 Fact | 제한 없는 비율 혜택으로 계산 금지 | FR-002 |
| **미래 지출** | 앞으로 12개월에 발생할 것으로 사용자가 입력·수정한 소비 계획 | 🟢 Decision | 과거 소비와 혼용 금지 | FR-001 |
| **과거 기준 대조군** | 최근 6개월 소비만 사용한 “기존 방식의 답”인 Mock 화면. CardFit 결과가 아님 | 🟢 Decision | 확정 가능한 추천으로 표현 금지 | FR-009 · D-007 |
| **게이팅** | 임계 통과 때만 변경을 제안하고 미달이면 현재 조합 유지를 반환하는 판단 | 🟢 Decision | 단순 필터링과 혼용 금지 | FR-003 |
| **근거 6항목** | 실적구간·혜택한도·연회비·제외조건·기준일·미반영 항목 | 🟢 D-004 | 임의의 6개 설명으로 대체 금지 | FR-005 |
| **Mock 데이터** | 실제 연동 없이 시연·UX 검증을 위해 고정한 예시 데이터 | 🟢 D-001 | 실제 카드 혜택/개인화 결과로 표현 금지 | FR-002/009 |

## 금지 표현

| 쓰지 않는 말 | 이유 | 대신 |
| --- | --- | --- |
| 최적의 카드 / 최고의 카드 | 단일 카드 추천으로 오해시킴 | 미래 지출 기준 조합안 |
| 실제 절감액 | Mock 계산이며 실행 결과가 아님 | 예시 Net Benefit / 예상 연간 차액 |
| 자동 해지 / 대신 신청 | 서비스 권한과 범위를 넘음 | 카드사에서 직접 신청·해지 |
| AI가 계산한 결과 | 계산은 규칙 엔진이 담당 | 규칙 기반 계산 결과 |
| 검증된 임계값 | D-002는 사용자 검증 전 팀 상수 | 프로토타입 판단 임계값 |
