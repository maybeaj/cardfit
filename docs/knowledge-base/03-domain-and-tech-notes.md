## 계산 경계

1. 입력 없는 달은 Mock 과거 패턴으로 채우고, 사용자가 입력한 미래 지출에만 ±20%를 적용한다: FR-002, D-003.
2. 계산 기간은 기준일로부터 12개월이며 결과는 연 단위다: D-005.
3. 사용 카드는 최대 2장, 신규 카드는 최대 1장이다: FR-003.
4. Net Benefit이 연 50,000원 이상이면서 Gross Benefit의 15% 이상일 때만 변경안을 반환한다: D-002. 검증 전 팀 상수다.
5. 근거 6항목이 없으면 결과를 노출하지 않는다: FR-005, D-004.
