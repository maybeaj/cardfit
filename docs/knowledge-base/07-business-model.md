## 7-1. 수익 모델 (T32 · keystone)

**결정(🟡):** 초기 = **사용자 무료 + 카드 발급 CPA(제휴 수수료)** 단일 경로. 확장은 파생 비전으로 후순위.

| 항목 | 결정 | 근거 질문 |
| --- | --- | --- |
| 초기 수익원 | 카드 발급 CPA. 사용자 과금 없음 | Q21 |
| 제휴 전 구간 | 아웃링크가 공식 홈 링크라 **수익 0**. 이 구간은 사용자·데이터 축적 기간으로 감내하고, 제휴 협상력은 *"미래 지출 입력 데이터 + 검증 트래픽"*으로 만든다 | H23 |
| 확장 비전(후순위) | B2B 타겟 광고(Q22) · B2C 구독·초개인화 리포트(Q23) · 캐시백 유치(Q24) · 타 금융상품(Q28). **단독 착수하지 않는다** — CPA 검증 후 파생 | Q22·Q23·Q24·Q28 |
| 단위 경제 | 마이데이터 호출당 비용 vs 발급 1건 수수료 마진은 **실연동 시 산출**, 현재 미정 🟡 | S23·Q27·Q30 |

**재검토 조건:** 유지 결론 비율(7-4)·조합안 선택률(7-4)·단위 경제 실측이 확보될 때.

## 7-2. 중립성 (T33 · depends 7-1)

**결정(🟡):** CPA를 받아도 **추천은 결정론 규칙엔진(Net Benefit)만으로 산출**하고, 제휴 단가가 순위·게이팅에 개입하지 못하게 방화벽을 둔다.

- **알고리즘 방화벽** — CPA/제휴 단가는 추천 순위·게이팅에 입력되지 않는다(`G-04` 확장). 유입 채널 제휴(웨딩·이사·가전, H25)도 동일하게 계산에 개입 금지 — **두 번째 압력원**.
- **수익 0 감수** — "현재 조합 유지" 결론에서 아웃링크·수익이 0이어도 그대로 반환한다(`G3`). 유지 비율 상한은 7-4.
- **사용자 확인 수단(H29)** — 화면에 *"카드사 제휴와 무관하게 계산됩니다"* 고지 + 근거 공개(차별점 ③)가 중립성의 증거다. 내부 원칙에 그치지 않는다.
- **데이터 사업화 경계(H28)** — 미래 지출 데이터는 **익명·집계 수준까지만** 활용하고 개인 식별·특정 브랜드 푸시는 하지 않으며, 활용 범위를 사용자에게 고지한다.

**재검토 조건:** 유지 결론 비율이 사업 감당선(7-4)을 넘어 중립성과 수익이 충돌할 때.

## 7-3. Moat·경쟁 (T34 · depends 7-1)

**결정(🟡):** 지속 가능한 차별은 기능 하나가 아니라 **데이터 + 중립 포지션 + 획득 채널**의 결합이다.

| 차별 축 | 내용 | 복제 난이도 |
| --- | --- | --- |
| 미래 지출 입력 데이터 | 카드사·경쟁사가 못 가진 자산 | 높음(사용자 축적 필요) |
| 검증 가능 계산 근거 공개 | 차별점 ③ — 약관과 대조 가능 | 중(신뢰 축적 필요) |
| 이벤트 트리거 획득 채널 | 7-5 | 중 |

- **카드사 자체 앱(H27)** — 자사 카드 한정 미래입력을 붙여도 *"여러 카드사 교차·중립 비교"*는 못 한다 → 우리가 남는 자리.
- **빅테크 복제 수명(S26·Q25)** — 미래반영 기능 자체는 복제 가능. 버티는 것은 데이터·중립 포지션·근거 공개 신뢰다.
- **카드사 포지셔닝(S25·Q26)** — *"고객이 우리 카드를 해지하게 만드는 위협"*이 아니라 *"최적 조합에 자사 카드를 넣어주는 고타겟 채널"*로 포지셔닝해 제휴 명분을 만든다.

**재검토 조건:** 경쟁사가 미래 반영을 출시하거나 카드사 자체 앱이 교차 비교를 도입할 때.

## 7-4. 지표 임계·성공/중단 조건 (T45 · depends 7-1)

**결정(🟡):**

| 지표 | 값 | 성격 |
| --- | --- | --- |
| North Star(조합안 선택률) | ≥ 40% 성공 · < 20% 피벗 | 팀 합의, 벤치마크 없음. 20% 피벗선은 E2 Concierge 기준 승계 |
| 유지 결론 비율 상한 | 과반 초과 시 수익 모델 경보 → 원칙(중립성)이 아니라 모델을 먼저 손본다 | 🟡 임계는 실측 후 확정 (H21) |
| 중단 조건 | 프로토타입 검증 후 **4주(🟡) 내 핵심 지표 미달 시 방향 재검토**, 판정 주체 = **팀 전원 합의** | S30·H30 — 종전엔 피벗선만 있고 시한·주체가 비어 있었다 |

**다음 단계 투자 정당화 한 문장(S30):**
> *"미래 지출을 반영한 중립·검증가능 카드 조합 계산이, 과거 기반 추천보다 높은 조합 확정률을 만든다"* — 프로토타입이 이를 보이면 실연동에 투자한다.

**재검토 조건:** 실사용 선택률 데이터 확보 시.

## 7-5. 진입 트리거 (T46 · depends 7-1)

**결정(🟡):** 6화면 흐름은 `[0]` 홈에서 시작하지만, **진짜 트리거는 흐름 밖의 이벤트(혼인·이사 확정)**다.

- **트리거 채널** — 웨딩홀·이사·가전 유통·청첩장 앱 등 **이벤트 시점 채널 제휴 유입** + 검색·직접 진입.
- **프로토타입 범위** — `[0]` 홈이 진입점(범위 내). 실제 획득 채널은 사업 범위다.
- **리스크(H22)** — 자체 리텐션이 Won't v1이라, 트리거를 **남이 쥐면** 이벤트 1회 계산 모델이 성립하지 않는다. 유입 채널 확보가 사업 성패이며 7-1의 제휴 전 구간과 직결된다.

**재검토 조건:** 유입 채널 CAC가 확인되거나 리텐션(현재 Won't v1) 재검토 신호가 인터뷰에서 나올 때.
