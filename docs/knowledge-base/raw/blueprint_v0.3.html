Current MVP Boundary & Open Gaps

확정본에서 아직 ‘미해결’로 남아 있는 항목을 프로토타입 기능으로 임의 구현하지 않았습니다.

SCOPE BOUNDARY

해지·전환 실행 대행

상담사 만류와 복잡한 절차는 실제 핵심 Pain이지만, CardFit은 해지 상담·신청을 대행하지 않습니다. 사용자 여정의 가장 큰 단절 위험으로 남습니다.

OPEN DECISION

실행 완주율 · 상태 추적

Value Proposition 확정본은 실행 완주율 지표, 만류 대응 안내, 실행 체크리스트·상태 추적 등을 후보로 남겨두고 있으며 채택 여부는 미확정입니다.

POST-MVP

구매 후 혜택 확인 · 리텐션

고객여정에는 구매 후 실제 혜택 확인 단계가 있지만, 지속 사용 동기(E)는 현재 대응 기능이 없는 영역입니다. 후속 MVP에서 별도 설계가 필요합니다.
