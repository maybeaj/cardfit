# ADR-003 — 사용자 진행 상태와 정본 데이터를 분리한다

- 상태: Accepted
- 결정일: 2026-09-01

## 맥락

신규 카드 공식 페이지를 새 탭으로 열고 돌아왔을 때 입력과 확정 조합은 유지돼야 한다. 동시에 기술 제약에 따라 Mock 데이터와 계산·확정 결과는 Prisma/Supabase에 저장할 수 있는 서버 경계를 둔다. 로그인과 실사용자 개인정보는 범위 밖이다.

## 결정

정본 데이터는 Server Actions를 통해 Prisma/Supabase에 저장한다. 외부 링크 복귀에 필요한 일시적 화면 상태만 React state와 `sessionStorage`에 저장한다. sessionStorage는 DB 정본을 대체하지 않는다.

## 결과

같은 세션의 외부 링크 복귀는 지원한다. 로그인 없는 단일 Mock 사용자이므로 새 사용자 인증과 브라우저 간 계정 복원은 지원하지 않는다.
