# ADR-003 — 사용자 진행 상태는 세션에만 보존한다

- 상태: Accepted
- 결정일: 2026-09-01

## 맥락

신규 카드 공식 페이지를 새 탭으로 열고 돌아왔을 때 입력·확정 조합·선택 탭은 유지돼야 한다. 반면 v0.1은 로그인·DB·개인정보 저장이 범위 밖이다.

## 결정

화면 상태는 React state와 `sessionStorage`에만 저장한다. 서버 전송과 영구 저장은 하지 않는다.

## 결과

같은 세션의 외부 링크 복귀는 지원한다. 새 세션·브라우저 간 복원과 장기 보존은 지원하지 않는다.
