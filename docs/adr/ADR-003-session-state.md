# ADR-003 — 사용자 진행 상태는 세션에만 보존한다

- 상태: Accepted · **2026-09-01 재확인** (`D-011`) — DB가 생겼어도 진행 상태는 서버에 저장하지 않는다
- 결정일: 2026-09-01

## 맥락

신규 카드 공식 페이지를 새 탭으로 열고 돌아왔을 때 입력과 확정 조합은 유지돼야 한다.

`D-011`로 Supabase Postgres가 범위에 들어왔지만, 사용자 진행 상태를 서버에 저장하면 **로그인·소유권 검증·동의 판정·파기 절차**가 따라온다. 그 항목들은 `D-012`에서 v1 로드맵으로 분리했다.

## 결정

화면 상태는 React state와 `sessionStorage`에만 저장한다. 서버 전송과 영구 저장은 하지 않는다.

**DB는 읽기 전용 Mock 저장소로만 쓴다** — Seed로 적재한 카드·소비·규칙을 읽고, 사용자가 입력한 계획과 확정 조합은 쓰지 않는다. 계산 결과도 서버에 남기지 않는다.

## 결과

같은 세션의 외부 링크 복귀는 지원한다. 새 세션·브라우저 간 복원과 장기 보존은 지원하지 않는다. 사용자 데이터가 DB에 없으므로 인증·동의·파기 요구사항이 발생하지 않는다.

`ClientEvent` 6종도 서버로 보내지 않고 콘솔·`localStorage`에만 남긴다 (`T30`).
