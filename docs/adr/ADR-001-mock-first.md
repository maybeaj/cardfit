# ADR-001 — v0.1은 Mock-first·Seeded Data로 구현한다

- 상태: Accepted
- 결정일: 2026-09-01

## 맥락

카드 이용내역은 마이데이터 채널이 필요하고 카드 혜택 규칙은 공식 통합 API가 없다. 실제 연동·인가·제휴·개인정보 통제를 프로토타입 범위에 넣지 않는다. 다만 제품 구조 검증을 위해 로컬 Supabase와 배포 Supabase PostgreSQL을 사용한다.

## 결정

보유카드·과거소비·혜택규칙은 명시적으로 표시한 Mock Seed를 사용한다. Seed 원본과 규칙 Fixture는 버전 관리하며, 실제 인증·동의·연결 성공처럼 표현하지 않고 `예시 데이터 연결하기`로 표시한다. 마이데이터·카드사 데이터 API와 AI는 사용하지 않는다.

## 결과

사용자 흐름과 계산 안전장치는 검증할 수 있지만 실데이터 정확성, 실제 연결 성공률, 카드사 약관 최신성은 주장하지 않는다. DB 연결과 Server Actions는 제품 동작에 필요한 최소 서버 계층으로 검증한다.
