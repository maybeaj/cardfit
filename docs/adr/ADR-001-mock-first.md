# ADR-001 — v0.1은 Mock-first로 구현한다

- 상태: Accepted
- 결정일: 2026-09-01

## 맥락

카드 이용내역은 마이데이터 채널이 필요하고 카드 혜택 규칙은 공식 통합 API가 없다. 32시간 안에 실제 인가·제휴·개인정보 통제를 구현할 수 없다.

## 결정

보유카드·과거소비·혜택규칙은 명시적으로 표시한 Fixture를 사용한다. 실제 인증·동의·연결 성공처럼 표현하지 않고 `예시 데이터 연결하기`로 표시한다.

## 결과

사용자 흐름과 계산 안전장치는 검증할 수 있지만 실데이터 정확성, 가용성, API 비용, 실제 연결 성공률은 주장하지 않는다.
