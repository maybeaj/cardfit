# ADR-002 — 금액 계산은 결정론적 규칙 엔진만 담당한다

- 상태: Accepted
- 결정일: 2026-09-01

## 맥락

카드 실적·한도·제외조건·연회비는 같은 입력에서 같은 결과를 내야 하며 근거를 다시 계산할 수 있어야 한다.

## 결정

계산과 배분은 순수 TypeScript 함수로 구현한다. 생성형 AI는 금액과 판정을 만들지 않는다. 입력 스냅샷과 `rule_version`으로 결과와 근거를 연결한다.

## 결과

동일 입력 불일치 0건과 배분 오차 1원 이하를 자동 검증할 수 있다. 규칙이 바뀌면 Fixture 정답셋과 테스트를 함께 갱신해야 한다.
