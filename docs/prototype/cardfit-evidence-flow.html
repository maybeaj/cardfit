복구가 완료되면 차단 화면이 자동으로 정상 결과 화면으로 바뀝니다. 즉, 사용자는 불완전한 추천을 받는 대신 무엇을 보완해야 하는지 알 수 있습니다.

이 HTML에서 일어나는 일

버튼을 누르면 실제 백엔드 호출 대신 브라우저 안의 상태가 바뀝니다. 이 상태 전환이 구현 시 FE 화면과 BE 도메인 로직 사이의 계약을 설명합니다.

정상 경로

1. 최근 12개월 소비와 앞으로의 계획 입력
2. 카드 후보별 혜택·비용 계산
3. 근거 6개 존재 여부 검증
4. 기준을 통과한 결과와 근거 공개

실패·복구 경로

  1. 근거 6개 중 하나라도 누락
  2. 추천 결과와 적용 CTA를 차단
  3. 누락된 항목과 사유를 화면에 표시
  4. 근거 복구 후 동일 입력으로 재검증

프로토타입 범위

Mock 데이터만 사용합니다. 카드사 인증, 실제 발급, 결제 내역 API, 영구 저장은 포함하지 않습니다.
