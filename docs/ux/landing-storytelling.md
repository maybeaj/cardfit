# CardFit 랜딩페이지 콘텐츠 계획서

> 상태: 🟡 초안 · 2026-09-02 (v0.4 프로토타입 기준으로 갱신)
> 상위 문서: `docs/PRD.md` · `docs/ux/README.md` 1절 · `docs/knowledge-base/raw/CardFit_Deck_10min_v2-2.md`(마스터덱 18장) · `docs/prototype/cardfit-prd-srs-v0.4.html`(앱 화면 목업 v0.4)
> 소유 레인: UX & Build (`docs/ux/**`)

이 문서는 실제 웹페이지(`/`)에 뜨는 **순서 그대로** 섹션마다 무슨 내용이 들어가는지 정리한다.
확정된 카피는 출처를 밝히고, 우리 자료에 없는 부분은 지어내지 않고 **미정**으로 남긴다.

## 지켜야 할 것

- 랜딩은 앱 데모의 파생물이다 — 화면 설명·금액은 `/app` 계산 결과와 어긋나면 안 되고, `src/content/copy.ts`·`src/domain/calc.ts`의 값을 그대로 쓴다. 랜딩에만 있는 숫자를 새로 만들지 않는다.
- 금지어: `총혜택`, `최대혜택`, `놓쳤어요`, `손해보고 있어요`.
- 페르소나(이서연·신은서·조민아)는 마스터덱에 **모의 응답**이라고 명시돼 있다 — 실제 고객 후기처럼 인용하지 않는다.
- 북극성 40%, 계산오류율 등 내부 검증 지표는 팀 자료용이다 — 고객 대상 화면에 노출하지 않는다.
- `docs/prototype/cardfit-prd-srs-v0.4.html`은 **앱 화면(iPhone 목업) 기준으로 대충 구상한 탐색용 프로토타입**이다. 랜딩(웹페이지)에 그대로 옮기지 않고, 이 문서가 웹 섹션 형태로 번역한 내용만 반영한다. 문구가 `CLAUDE.md` 확정 제약과 어긋나면 **`CLAUDE.md`가 우선**한다.
- **운영진 관점이 아니라 사용자 관점으로 쓴다.** 계산 공식(`Net Benefit = Gross − 연회비 − …`), 임계값을 수식 그대로 노출(`≥ 50,000원 AND 15%`), "내부 기준", "게이트", "임계 판정", FR 번호, SRS·mermaid 흐름도 노드 이름을 카피에 그대로 쓰지 않는다. 사실은 유지하되 "당신에게 무엇이 좋은지"를 말하는 문장으로 바꿔 쓴다 — 예: "순혜택 ≥ 50,000원 AND 15% 이상"이 아니라 "1년에 최소 5만원, 그리고 눈에 띄게 유리할 때만요".

## 8. 왜 믿을 수 있냐면요 (계산 신뢰)

내부 공식·임계값 자체를 카피로 노출하지 않는다 — "운영진 관점" 피드백 이후 사용자 언어로 다시 썼다. 사실은 아래 "출처"의 공식 값과 정확히 같다.

| 항목 | 내용 | 출처(사실 근거) |
| --- | --- | --- |
| 제목 | 사람이 지어낸 숫자가 아니라, 카드사 약관 그대로 계산해요 | `CALC_NOTICE.engine`(`src/content/copy.ts`)의 의미를 사용자 언어로 |
| 계산 단계 4개 | 알려주신 12개월 계획을 그대로 살펴봐요 / 카드마다 실적 구간·한도·제외 조건까지 꼼꼼히 따져요 / 지금 쓰는 카드 최대 2장 + 새 카드 최대 1장 안에서 조합을 찾아요 / 바꿀 만큼 이득인지 마지막으로 확인해요 | `CALC_NOTICE.steps` 재작성 |
| 변경 권하는 기준 | "1년에 최소 5만원, 그리고 눈에 띄게 유리할 때만요" | 수치 자체는 `NET_BENEFIT_FLOOR`(50,000원)·`NET_BENEFIT_RATIO`(15%) 그대로, 공식·기호(`≥`, `AND`)만 뺐다 |
| 애매하면요 | "지금 카드가 낫다"고 솔직히 말씀드려요 — 이것도 정상적인 결과예요 | `CONCLUSION_COPY.hold` 계열 의미 |
| 각주 | 이 기준은 어디서 가져온 평균값이 아니라, 애매한 이득으로 괜히 카드를 바꾸시게 하고 싶지 않아서 신중하게 정한 최소 기준이에요 | "내부 기준"·수식 표기를 뺀 재작성. 사실관계는 현행 각주와 동일 |

## 결정 사항 (이번 개정에서 확정)

- 히어로 헤드라인·서브카피·1차 CTA는 **v0.4 프로토타입 문구를 채택**했다("앞으로 쓸 돈까지 반영해…" / "카드조합 추천받기"). 마스터덱·기존 배포본 문구는 참고용 대안으로만 남긴다.
- 히어로에 특정 혜택 금액(예: "+186,000원")을 **넣지 않기로** 했다 — v0.4 s0 히어로에도 숫자가 없고, 공식 Fixture(186,000원)와 v0.4 자체 예시 숫자(486,000원 등)가 서로 달라 혼선을 피하려는 목적이다.
- 이용 흐름·화면 미리보기 섹션 문구는 v0.4의 각 화면(s0~s7) 문구를 웹 섹션 형태로 옮겼다.
- **전면 재작성 — 운영진 관점 → 사용자 관점.** 계산 공식·수식 기호(`≥`, `AND`)·"내부 기준"·"게이트"·"근거 6가지"처럼 SRS·mermaid에서 그대로 가져온 표현을 전부 사용자 언어로 바꿨다. 자세한 내용은 8·9절 참고.
