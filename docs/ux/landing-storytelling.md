# CardFit 랜딩페이지 콘텐츠 계획서

> 상태: 🟡 초안 · 2026-09-02
> 상위 문서: `docs/PRD.md` · `docs/ux/README.md` 1절 · `docs/knowledge-base/raw/CardFit_Deck_10min_v2-2.md`(마스터덱 18장)
> 소유 레인: UX & Build (`docs/ux/**`)

이 문서는 실제 웹페이지(`/`)에 뜨는 **순서 그대로** 섹션마다 무슨 내용이 들어가는지 정리한다.
확정된 카피는 출처를 밝히고, 우리 자료에 없는 부분은 지어내지 않고 **미정**으로 남긴다.

## 지켜야 할 것

- 랜딩은 앱 데모의 파생물이다 — 화면 설명·금액은 `/app` 계산 결과와 어긋나면 안 되고, `src/content/copy.ts`·`src/domain/calc.ts`의 값을 그대로 쓴다. 랜딩에만 있는 숫자를 새로 만들지 않는다.
- 금지어: `총혜택`, `최대혜택`, `놓쳤어요`, `손해보고 있어요`.
- 페르소나(이서연·신은서·조민아)는 마스터덱에 **모의 응답**이라고 명시돼 있다 — 실제 고객 후기처럼 인용하지 않는다.
- 북극성 40%, 계산오류율 등 내부 검증 지표는 팀 자료용이다 — 고객 대상 화면에 노출하지 않는다.

## 3. 문제 제기 (신규 제안 — 현재 배포 페이지엔 없음)

마스터덱은 히어로 다음에 바로 "기존 vs CardFit 대비"로 들어가는데, 그 앞에 **문제 자체의 대비 한 줄**을 넣으면 왜 다른지가 먼저 와닿는다.

| 항목 | 내용 | 출처 |
| --- | --- | --- |
| 왼쪽(기존) | 지난 1년, 이미 쓴 돈 → "어떤 카드가 좋았나?" | 마스터덱 슬라이드 9 |
| 오른쪽(CardFit) | 앞으로 3개월, 곧 쓸 돈 → "지금 무엇을 준비해야 하나?" | 마스터덱 슬라이드 9 |
| 채택 여부 | **미정** — 이 섹션 자체를 넣을지는 팀 확인 필요. 넣는다면 4번 "차이 비교" 섹션 바로 앞에 붙는다 | — |

## 4. 차이 비교 (기존 추천 vs CardFit)

| 항목 | 내용 | 출처 |
| --- | --- | --- |
| 기존 추천 | 지난 1년 소비 → 카드 한 장 비교 → 발급 페이지 연결 | `src/app/page.tsx` 현행 (마스터덱 슬라이드 5와 동일 구조) |
| CardFit | 현재 소비 확인 → 앞으로 쓸 돈 입력 → 카드 조합 재계산 → 근거 확인 → 카드사 연결 | 현행 |
| 캡션 | 차이는 발급 연결이 아니라, 그 전에 '미래 입력'과 '조합 계산'을 거친다는 점입니다 | 현행 (마스터덱 슬라이드 5 원문과 동일) |

## 하지 말아야 할 것

- 페르소나를 실제 고객 후기처럼 인용하지 않는다.
- 북극성 40%, 계산오류율 등 내부 검증 지표를 노출하지 않는다.
- 마스터덱에만 있고 앱 계산엔 없는 숫자(시장 규모 1억 7,734만 건, 혼인 24만 건 등)를 고객 대상 가치 제안에 섞지 않는다.
- 문제 제기를 공포 소구로 과장하지 않는다.
