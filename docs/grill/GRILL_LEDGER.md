## 화면 계약

1. 마이데이터 연결 상태 확인
2. 앞으로 쓸 돈 확인·수정
3. 변경 조건 확인
4. 현재 카드 조합 계산
5. 미래지출 기준 카드 조합 계산
6. 단일 조합 결과 확인 — 카드별 `신규·유지·정리`
7. 배분·계산 근거 확인
8. 조합 확정 및 신규 카드 공식 페이지 이동

## 용어

| 용어 | 뜻 |
| --- | --- |
| 신규 | 현재 없지만 결과 조합에 추가할 카드 |
| 유지 | 현재 보유 중이고 결과 조합에서도 계속 쓸 카드 |
| 정리 | 현재 보유 중이지만 결과 조합에서는 사용하지 않을 카드. 해지를 뜻하거나 대행하지 않는다 |

## 근거 경계

- 기각된 원문은 근거로 사용하지 않는다.
- `연 5만원 AND 15%`는 사용자 조사 결과가 아니라 프로토타입에서 비교 동작을 검증하기 위한 팀 합의 상수다.
- 카드 혜택 수치는 Mock이며 실제 상품 추천이나 혜택 보장을 의미하지 않는다.
- 카드 상태는 `신규·유지·정리` 세 값만 허용한다.

## 남은 검증

- 실제 사용자가 미래지출 제안값을 이해하고 수정할 수 있는가
- `신규·유지·정리`가 카드 조합의 변화를 바로 이해하게 하는가
- 근거 화면이 추천에 대한 신뢰와 결정 확신을 높이는가
- 임계값은 실사용 데이터가 생기면 선택률·후회율·과잉 변경률로 다시 조정한다
