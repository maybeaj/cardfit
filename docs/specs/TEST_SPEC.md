> 상태: 🟢 구현 기준본 · 단위: Vitest · E2E: Playwright

## 1. 검증 원칙

계산 정확성은 정답셋 비교로, UX 경계는 사용자 흐름으로 검증한다. 실연동·사용자 조사·선택률은 이 프로토타입의 테스트 통과 주장에 포함하지 않는다.

## 3. 계산 단위 테스트

- 임계 경계: `49,999/50,000원`, Gross의 `14.99/15%`를 각각 검증한다.
- 같은 입력을 3회 실행해 결과 객체의 깊은 동등성을 확인한다.
- 동률 후보가 정해진 순서로 선택되는지 확인한다.
- 배분 합과 입력 총액의 차이가 1원 이하인지 확인한다.
- 연회비를 안분하지 않으며 7개월 이후 발급 고지가 생성되는지 확인한다.
- 출처 없는 `unmodeled_bound`가 결과에서 제외되는지 확인한다.

## 4. E2E·반응형

- `change_case`와 `maintain_case` 모두 온보딩부터 확정까지 같은 흐름으로 완주한다.
- 402×874와 1440×900에서 가로 스크롤 없이 핵심 CTA와 결론이 보인다.
- 외부 링크를 새 탭으로 연 뒤 돌아오면 입력과 확정 조합이 유지된다.
- 금지어와 Mock 오인 문구를 정적 스캔한다.

## 5. 완료 판정

P0 테스트 전부 통과, 알려진 콘솔 오류 0건, 비밀키·개인정보 스캔 0건이어야 프로토타입을 완료로 표시한다. 사용성·선택률은 관찰하지 않았다고 별도로 고지한다.
