# Calculation Spec — CardFit

> 상태: 🟢 구현 기준본 · 상위 요구사항: `FR-002~005`, `AC-001~006·010`

## 1. 입력과 기간

- 기준 기간은 계산 기준일부터 12개월이다.
- 입력 화면은 과거 패턴으로 채운 제안 초안이며, 사용자가 `이 계획대로 계산하기`를 누르면 화면의 전체 값을 앞으로 12개월 계획으로 확정한다.
- 시점이 있는 미래지출은 해당 월 값을 사용하고, 나머지 월은 제안된 과거 패턴 기저를 사용한다.
- 모든 항목 삭제 또는 금액 전부 0이면 계산하지 않는다. 별도 “30% 입력” 기준은 없다.

## 2. 시나리오

| ID | 계산 | 화면 라벨 |
| --- | --- | --- |
| `LOW` | 사용자가 확인한 미래 변경분 × 0.8 | 예상보다 20% 적게 쓸 경우 |
| `EXPECTED` | 사용자가 확인한 미래 변경분 × 1.0 | 예상대로 쓸 경우 |
| `HIGH` | 사용자가 확인한 미래 변경분 × 1.2 | 예상보다 20% 많이 쓸 경우 |

과거 패턴 기저에는 ±20%를 적용하지 않는다. 세 결과는 한 번에 계산하며 기본 탭은 항상 `EXPECTED`다.

## 3. 후보 조합

- 기존 카드는 `유지` 또는 `해지`, 후보 카드는 `신규 추가` 상태를 가진다.
- 결과 조합의 사용 카드는 최대 2장, 신규 카드는 최대 1장이다.
- 사용자가 신규 발급을 허용하지 않으면 신규 후보를 생성하지 않는다.
- 모든 유효 후보와 현재 조합을 같은 규칙 버전으로 평가한다.

## 4. 손익과 권장 판정

```text
Gross Benefit = 12개월 동안 규칙·실적·한도·제외 조건을 적용한 혜택 합계
Switching Cost = 연회비 + 실적 재적립 손실 + 발급 대기 비용
Net Benefit = Gross Benefit - Switching Cost
```

변경은 다음 두 조건을 **모두** 충족할 때만 권한다.

```text
Net Benefit >= 50,000원
Net Benefit >= Gross Benefit × 15%
```

이는 사용자 조사 결과가 아니라 과잉 추천을 막기 위한 팀 합의 상수 `D-002`다. 화면·발표에서 시장의 보편 기준으로 표현하지 않는다. 하나라도 미달이면 `현재 조합 유지`가 정상 결과다.

연회비는 12개월 창 안에서 안분하지 않는다. 카드 발급 시점이 7개월 이후면 근거에 “연회비가 12개월 창에 통째로 반영됨”을 표시한다.

## 5. 배분과 동률

- 카테고리별로 실적·한도·제외 조건을 만족하면서 한계 혜택이 가장 큰 카드에 금액을 배분한다.
- 배분 합은 입력 총액과 같아야 하며 허용 오차는 1원이다.
- 후보의 Net Benefit이 같으면 `신규 카드 수가 적은 조합 → 전체 카드 수가 적은 조합 → 조합 ID 오름차순`으로 결정한다.
- 동률 규칙까지 적용한 결과는 같은 입력에서 항상 같아야 한다.

## 6. 근거 계약

결과마다 실적구간, 혜택한도, 연회비, 제외조건, 기준일, 미반영 항목의 6개 항목을 제공한다. `unmodeled_bound`는 출처와 기준일이 있는 값만 `최대 ±n원`으로 별도 표시하며 결론 차액에 더하지 않는다. 하나라도 필수 근거가 빠지면 결과 노출을 거부한다.
